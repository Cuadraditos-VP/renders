# Renders Gallery (PWA)

Galería para organizar renders en carpetas.  
Funciona como **aplicación instalable** en PC y móvil.

## Cómo ponerla en GitHub (2 minutos)

1. Crea un repositorio nuevo en GitHub
2. Sube **todos** los archivos de este ZIP
3. Ve a **Settings → Pages**
4. Source → **Deploy from a branch**
5. Branch: `main`  →  Folder: `/ (root)`  →  **Save**
6. Espera 1 minuto y entra a la URL que te da GitHub  
   (ejemplo: `https://tu-usuario.github.io/nombre-del-repo/`)

## Cómo instalarla en la PC

1. Abre la URL de GitHub Pages en **Chrome** o **Edge**
2. En la barra de dirección aparece el icono de **Instalar** (o menú ⋮ → “Instalar Renders Gallery”)
3. Confirma → se abre como una app independiente

También funciona en Android (Chrome → “Añadir a la pantalla de inicio”).

## Uso

- Crea carpetas y sube tus renders
- Navega con las flechas ← → en la vista previa
- Usa el botón **↓ ZIP** para descargar todo cuando quieras guardar

## Nota

Las imágenes se mantienen solo mientras la app está abierta.  
Usa el botón ZIP para guardarlas de forma permanente.
